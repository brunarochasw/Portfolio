# Portfolio
Este projeto foi desenvolvido com o objetivo de apresentar minhas informações profissionais, habilidades, projetos e interesses na área de tecnologia. O portfólio foi criado como parte do meu processo de aprendizado em desenvolvimento web e serve como um espaço para compartilhar minha trajetória acadêmica e projetos desenvolvidos.
Tecnologias Utilizadas: JS, HTML, CSS
Funcionalidades
Página inicial com apresentação pessoal
Seção "Sobre Mim"
Exibição de habilidades e interesses
Navegação entre páginas
Elementos interativos desenvolvidos com JavaScript
Demonstrei meus conhecimentos em desenvolvimento web, organização de conteúdo e criação de interfaces responsivas, além de reunir informações relevantes sobre minha formação e áreas de interesse, com destaque para Cibersegurança e Engenharia de Software.
